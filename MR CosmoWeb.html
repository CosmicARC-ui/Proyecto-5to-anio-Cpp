Introducción

El proyecto consiste en desarrollar un Monitor de Rendimiento de PC mediante una aplicación de consola programada en C++. El programa simula el comportamiento de una computadora mientras ejecuta distintos juegos y aplicaciones, mostrando diferentes valores de rendimiento del sistema.

La simulación trabaja con variables que representan el uso de CPU, GPU y RAM, los FPS en juegos, temperaturas, consumo energético, velocidad de ventiladores, almacenamiento y datos de conexión. Los valores cambian durante la ejecución para representar un comportamiento dinámico.

Objetivo

El objetivo del proyecto es representar de manera sencilla cómo podría funcionar un monitor de rendimiento mientras un equipo ejecuta diferentes tipos de software. Para conseguirlo, el programa utiliza funciones, variables, estructuras de control, generación de valores aleatorios, menús y almacenamiento de información en un archivo de texto.

También diferencia entre juegos y aplicaciones de edición. Los juegos incluyen FPS y datos de conexión, mientras que las aplicaciones trabajan principalmente con el uso de componentes, temperaturas, consumo y almacenamiento.

Funcionamiento general

Al iniciar el programa se muestra una advertencia indicando que los datos corresponden a una simulación. Luego se presenta la identificación de la institución y el título del monitor. El usuario ingresa un nombre y el programa simula el ingreso de una contraseña.

Después aparece el menú principal. Desde allí se puede acceder al menú de juegos y aplicaciones. En cada opción se ejecuta una función específica que recibe valores base y genera las mediciones durante la sesión.

Algoritmos utilizados

El proyecto utiliza valores base y pequeñas variaciones aleatorias para evitar que las mediciones sean siempre idénticas. Por ejemplo, los FPS se calculan a partir de un valor base más una variación aleatoria.

FPSactual = FPSBaseJuego + (rand()%41 - 10); gpuActual = gpuBaseJuego + (rand()%21 - 10) / 10.0; cpuActual = cpuBaseJuego + (rand()%21 - 10) / 10.0; ramActual = ramBaseJuego + (rand()%11 - 5) / 10.0;

Cálculo de ventiladores

Las RPM del ventilador de CPU y GPU se calculan según la temperatura. A medida que aumenta la temperatura, también aumenta el rango de RPM utilizado por la simulación.

Promedios

Durante una sesión se acumulan las mediciones de CPU, GPU, RAM, FPS, temperaturas y consumo. Al finalizar, el programa divide los valores acumulados por la cantidad de mediciones para obtener promedios.

Informe de sesión

Al finalizar el monitor, el programa crea un archivo llamado “Informe de la Sesion.txt”. Allí guarda los datos principales obtenidos durante la ejecución.

Conclusión

El Monitor de Rendimiento PC reúne diferentes conceptos de programación para construir una simulación interactiva. El proyecto utiliza funciones separadas para juegos y aplicaciones, menús, variables acumuladoras, generación aleatoria, temporizadores, entrada de teclado y escritura de archivos.

De esta manera, la aplicación representa de forma sencilla cómo un monitor podría mostrar información del equipo mientras se ejecuta determinado software.
